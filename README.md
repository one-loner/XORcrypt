## XOR File Encryptor

Набор из двух Python-скриптов для шифрования и расшифрования файлов с помощью побитовой операции XOR.
## Состав проекта:
    encrypt.py — шифрование файла;
    decrypt.py — расшифрование файла;
 
## Требования

    Python версии 3.7 или выше;
    операционная система Windows, Linux или macOS.

Дополнительные библиотеки устанавливать не требуется.


## Принцип работы

Исходный файл побитово складывается по модулю два с ключом. Сложение по модулю два выполняется с помощью операции XOR. Если ключ заканчивается раньше исходного файла, он используется циклически. Перед началом шифрования ключ смещается на заданное количество бит. Например, при смещении 13 первый бит исходного файла будет складываться по модулю два с 14-м битом ключа. Поскольку операция XOR обратима, расшифрование выполняется тем же алгоритмом.
   
Формат зашифрованного файла:   
Первые 64 байта содержат смещение в битах в виде беззнакового числа с порядком байтов big-endian.   
Остальная часть файла содержит зашифрованные данные.   

Шифрование:   

python3 encrypt.py <исходный_файл> <файл_ключа> <смещение_в_битах>

    
   
К имени исходного файла автоматически добавляется окончание .crypt.


Расшифрование:   

python decrypt.py <зашифрованный_файл> <файл_ключа>


Если имя файла заканчивается на .crypt, это окончание удаляется.    
Если зашифрованный файл не имеет окончания .crypt, его расширение заменяется на .result.   

Для расшифрования необходимо использовать тот же файл ключа, который применялся при шифровании.   

Если использовать другой ключ или изменить содержимое ключа, исходные данные восстановить нельзя.
